Shareable pages

Tag the notes you want to share and say who the page is for. You get back one web page that opens anywhere, and your notes stay where they are.

How it works

Tag
Vault files get a content-tag in their visibility array
Cut config
Names tag, audience, lens, output, window
Body sections
Override the contact overlay, then template defaults
Contact overlay
The contact’s rendering preferences layer over style tokens
Frame
Renders one self-contained HTML packet
Voice pass
Runs after render, before structural checks

Settled

Tag is a pointer
Files are never copied, tags never stripped
Cut and lens
A cut is author-routed; a lens is queried from a tagged pool
Output is canonical
A mirror is byte-identical and written by the build
Audio player
On unless the cut turns it off
Feedback log
Append-only; re-cuts respect applied entries
