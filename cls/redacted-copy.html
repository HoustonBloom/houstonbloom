What a person gets

A redacted copy of your manifest for one person: when you were active together, and the rows that name them. It is the only file that leaves.

Sam Lee and the rows are made up. The copy shown is what the tool wrote on a test folder. The tool writes the copy; it sends nothing. You send it.

What each field holds

audience
Who the copy is for, the name given with --to.
madeAt
The day the copy was written.
activity
One entry per exchange on file with that person, newest first. Each holds only at, the timestamp. Read from records/<per_id>/exchanges.jsonl in your contacts folder when you give --person. Left out when you do not.
rows
Each manifest row whose visibility names that person, newest first: id and lastActive, nothing else.
id
The row's 64 random hex characters. It gives nothing away about the folder, the file or your system.
lastActive
The day that row last changed.

Never in a copy: path, hash, project, sent, visibility, private rows, and rows that name only other people. What each exchange carried stays in your contacts folder.

What the file looks like inside

JSON, a plain text format. The command, what it printed, then manifest/manifest.sam-lee.redacted.json as the tool wrote it.

node map.mjs redact --to "Sam Lee" --contacts Documents/contacts --person per_sam-lee
