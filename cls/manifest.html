What the manifest is

One file on your computer. One row per top-level folder you name, and one per thing you make to share.

The rows below are made up to show the shape. Paths are shortened. The ids came from a real run of the tool on a test folder.

The picture

The manifest, as a table

One row is one folder or one shareable. A field is one column. Ids are shown by their first 8 characters; the tool accepts that too.

What each field holds

id
64 random hex characters, given once, never changed. It is not made from the name, the path or the contents, so it gives nothing away.
kind
folder, for a top-level folder you named, or shareable, for something made to send or something that came back.
path
Where it sits on your computer. In the manifest only, never in a redacted copy.
visibility
Who may see the row, as a list. ["private"] stands alone. Otherwise any of public and people's names, read as public + Sam Lee. Every folder starts private.
lastActive
The day it last changed, from its modified time. Checked at session end.
mappedAt
Folders: the day it was mapped.
madeAt
Shareables: the day it was made or received.
sent
Shareables: each send, with the day, who, and whether it was published.
from
A shareable that came back: who sent it.
relates_to
The id of the shareable this one answers.
project
The project a shareable belongs to, when it has one.
hash
A fingerprint of a shareable's contents, to tell an edit from a touch. Never shared.
notes
Transformation notes attached to a shareable: the day and the note's path.
missing
The day session end could not find the row. Nothing is deleted.
